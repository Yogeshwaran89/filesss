# Calculator and HTML Learning Project

This project contains a comprehensive Python calculator and a simple HTML/CSS learning page.

## Python Calculator

The `yokii.py` file defines a `Calculator` class that supports:

- Basic arithmetic: addition, subtraction, multiplication, division, floor division, and modulo
- Powers and roots, including square roots, cube roots, and nth roots
- Trigonometric and inverse trigonometric functions using degrees
- Logarithmic and exponential calculations
- Rounding, absolute values, floor, and ceiling operations
- Factorials, greatest common divisor, and least common multiple
- Percentages and percentage changes
- Calculation history for recorded operations

### Example

```python
from yokii import Calculator

calculator = Calculator()
print(calculator.add(10, 5))
print(calculator.square_root(16))
```

## HTML Learning Page

The `index .html` file is a complete guide demonstrating HTML elements, navigation, forms, code examples, layout grids, and basic styling. Its styles are connected to `file.css`.

## Running the Python File

Run the calculator module from a terminal with:

```bash
python yokii.py
```

The project is intended for practicing Python functions, object-oriented programming, HTML structure, and CSS styling.
